# estrategia/ — las bases del canal

Aquí viven las definiciones fundacionales de Entender Chile: qué es, para
quién, qué resuelve y cómo se financia. Todo lo demás (prompts, títulos,
miniaturas, series, tono, auspicios) debe poder derivarse de estos archivos.
Cuando una decisión editorial contradiga lo que dice esta carpeta, o se
cambia la decisión o se cambia la base — nunca conviven en contradicción
silenciosa.

Relación con las otras carpetas:

    estrategia/  fundamentos y rumbo (cambia poco, se cita mucho)
    ideas/       backlog táctico (features del pipeline, mejoras puntuales)
    contenido/   el producto

Archivos:
- `identidad.md` — qué es, propósito, propuesta de valor, qué NO es, tono
- `publico.md` — para quién (hipótesis a validar con analítica real)
- `modelo-de-negocio.md` — cómo se financia, hitos, plazos y riesgos
- `hoja-de-ruta.md` — la lista maestra de lo que falta resolver, por fases
- `decisiones.md` — registro de decisiones: fecha, qué, por qué, evidencia

Reglas:
- Cada documento declara su estado: BORRADOR / HIPÓTESIS / DECIDIDO.
- Cada afirmación importante lleva respaldo (fuente o experimento) o se
  marca explícitamente como hipótesis. El mismo estándar que el canal usa
  en pantalla, aplicado a sí mismo.
- `[POR DEFINIR — Santiago]` marca lo que solo el dueño puede decidir.
- `decisiones.md` cumple doble función: memoria del proyecto y REGISTRO DEL
  APORTE EDITORIAL HUMANO que exige la política de contenido inauténtico
  del YPP (checklist exacto en ideas/investigacion-crecimiento-2026-08-25.md).
