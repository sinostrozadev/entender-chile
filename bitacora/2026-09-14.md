## Lo aprendido, para no volver a pagarlo

- Las rutinas creadas por agente SÍ nacen con el repo si se pasa `sources`.
- La API del webhook exige `hook_type=app`, `source`, `scope_id`, `events`;
  no acepta filtro por rama. El disparo trae `Ref` y SHA, así que una rutina
  puede filtrar sola.
- El payload del `/fire` llega marcado como dato no confiable: el prompt
  tiene que decir cómo tratarlo (ya lo dice el punto 0 de la revisión).
- Actions no puede abrir PR en este repo; los PR permanentes los crea una
  persona una vez.
