# ideas/ : el backlog editorial del canal

Toda idea que surja (en conversaciones con Claude, con ChatGPT, o de Santiago)
se anota aquí para que no se pierda. Este directorio se commitea, como todo lo
editorial.

## El flujo real (estándar del 13-09-2026)

    ideas/evaluar.md  →  bitacora/PENDIENTES.md  →  bitacora/REALIZADOS.md
                      ↘  ideas/descartadas.md (con el porqué)

- **`ideas/evaluar.md`** es material crudo: una entrada por idea, con fecha, qué
  es, valor esperado y esfuerzo estimado. Nada más se hace desde acá.
- **Cuando una idea se aprueba baja a `bitacora/PENDIENTES.md`**, que es la
  única lista viva del proyecto (regla dura 41): ahí vive con evidencia
  (archivo y línea) y con dueño (noche, día o Santiago). Lo que no está ahí, no
  se hace.
- **Lo terminado se BORRA de PENDIENTES** y queda con su fecha en
  `bitacora/REALIZADOS.md`, que además es la evidencia de aporte humano que
  pide YouTube.
- **Las descartadas conservan la razón**: una idea descartada con contexto vale
  más que una idea olvidada. Si la decisión es de fondo, o es la decisión de NO
  hacer algo, va también a `estrategia/decisiones.md`, porque si no la auditoría
  la vuelve a proponer cada mañana.

`ejecutar.md` y `hechas.md`, las dos etapas intermedias que este README
describía antes, están en `archivo/` desde el 02-09-2026: eran listas sin
movimiento y nada pasó nunca de una a otra.

## Los otros archivos de esta carpeta

No todo lo de acá es una tarea. Varios son análisis de forma y distribución que
se consultan cuando toca decidir algo: retención, imagen, viralización,
formato, fondos, tarjetas, promesas de campaña, catástrofes naturales, la ruta
del Estrecho. Se leen, no se ejecutan; si de uno sale algo que hacer, esa parte
baja a PENDIENTES como cualquier otra idea.

`historia-de-chile-temario.md` es material de una serie posible (el temario
completo de Historia de Chile), no una tarea: está aquí desde el 26-09-2026
esperando que se decida si la serie se hace.
