# ideas/ - el backlog del canal

Toda idea que surja (en conversaciones con Claude, con ChatGPT, o de Santiago)
se anota aquí para que no se pierda. Flujo de vida de una idea:

    evaluar.md  →  ejecutar.md  →  hechas.md
                        ↘  descartadas.md (con el porqué)

Reglas:
- Una idea = una entrada con fecha, qué es, valor esperado y esfuerzo estimado.
- Al cambiar de etapa, la entrada SE MUEVE de archivo (no se duplica).
- Las descartadas conservan la razón: una idea descartada con contexto vale
  más que una idea olvidada.
- Este directorio se commitea, como todo lo editorial.
