# Las de papel: el set viejo, recuperado el 27-09-2026

Santiago, viendo las planas de color: "me gustaba más las imágenes de
secciones que teníamos antes, esas que eran blancas con texturas".

Son estas. Vivían en `public/fondos/seccion-<slug>.jpg` desde el 03-09-2026,
cuando los fondos de sección se encendieron por primera vez, y se dejaron de
usar cuando la secuencia del 24-09 pasó a pedir una imagen por sección en
`contenido/secciones/`. Nunca se borraron.

Qué son: papel hueso (#F2F2EF, el papel de la casa) con una trama fina de
cuadrícula o rayado, un motivo grande dibujado a línea en la mitad derecha y
el acento en verde pátina (#2F7263). La mitad izquierda queda limpia, que es
justo lo que pide la secuencia para el texto.

Miden 1376x768, no 1920x1080. Para fondo a pantalla completa se escalan un
40%, así que la trama fina se engorda y la línea pierde filo. Si el set se
adopta, conviene rehacerlas a 1920x1080 con el mismo prompt.

Faltan dos de las doce: `emergencia` y `deporte`.
