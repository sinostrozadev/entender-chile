# Estilo "Color": a propósito vacío

Esta carpeta no tiene imágenes y no es un olvido. Cuando una sección no tiene
imagen, el video la pinta con **su color y su pictograma grabado detrás**, que
es lo que hoy le pasa a Deporte. Activando este estilo, eso le pasa a todas.

No hay que escribir código para que exista: un estilo es una carpeta y el
video ya sabe qué hacer cuando no encuentra nada dentro.

Si alguien deja una imagen acá, el estilo deja de ser lo que dice ser.
