# Carátulas pedidas por OTROS canales de Santiago

Una carpeta por canal (`linea-punteada/`, `numeros-rojos/`, `bolita-lab/`…). Las deja GPT cuando atiende un
`contenido/urgente/PEDIDO-<canal>-<slug>.md` con `Tarea: imagen` y `Salida:` apuntando aquí. El prompt va
completo dentro del pedido (sección "Pedidos externos" de `prompts/imagen-caratula.md`). El canal que pidió la
descarga por `raw.githubusercontent.com` (repo público), la verifica y la guarda en su propio repo; lo que queda
aquí es el registro. Procedimiento completo: skill global `caratulas-con-gpt`.
