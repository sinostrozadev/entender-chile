# Banco de palabras

La cola. Se saca una por día (ver README). Al publicarse, se anota la fecha
en la columna y no vuelve a salir.

Criterio de entrada: aparece o puede aparecer en una noticia chilena este
mes. Las agrupadas por familia se pueden soltar juntas cuando el tema esté
en la conversación (por ejemplo, todo el bloque judicial cuando haya una
formalización grande).
